    직원 현황

      가상 시세와 규칙 기반 모의 에이전트로 움직이는 화면입니다. 실제 시장 데이터나 실제 매매가 아닙니다.

      보유 포지션

      종목담당수량평균가현재가평가액손익진입일

      포지션은 다음 거래일로 넘어갈 수 있고, 주 마지막 거래일 마감 15분 전에 전부 정리됩니다.

      매매 기록

      시각(ET)담당구분종목금액가격수수료

      매매 규칙

      • 보고 체계시니어가 시황을 보고하면 팀장이 전략을 지시합니다. 주니어는 담당 시니어에게 선보고하고 승인받아야 매매합니다.
      • 모든 주문은 리스크 데스크로에이전트는 의견만 냅니다. 주문은 리스크 매니저의 한도 검사를 통과해야 서버로 갑니다.
      • 하루 목표 +0.5%달성하면 신규 매수를 멈추고 청산만 허용합니다. 목표는 상한이지 채워야 할 숫자가 아닙니다.
      • 손실 한도 −1%닿으면 전량 청산하고 그날 매매를 멈춥니다.
      • 비중 한도종목당 10%, 주문당 5%, 총 노출 50%, 포지션별 손절 1.5%, 하루 20건.
      • 보유기간필요하면 다음 날로 넘길 수 있습니다. 주 마지막 거래일엔 마감 30분 전부터 매수 금지, 15분 전 전량 청산합니다.
      • 수수료 0.25%매수·매도 각각 거래대금의 0.25%. 한 번 사고팔면 0.5%입니다.
      • 실계좌는 사람 승인실계좌 모드에서는 주문마다 사장님(나)이 터미널에서 yes를 입력해야 전송됩니다.

      내 PC에서 python serve_office.py로 실행하면 이 화면이 Python 오피스의 실제 진행 상황을 실시간으로 보여줍니다. 하루 요약 화면(이전 버전)
