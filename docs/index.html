AI 트레이딩 오피스의 하루

시니어가 시황을 보고하면 팀장이 전략을 지시하고, 주니어는 시니어에게 선보고한 뒤에만 매매합니다. 모든 주문은 리스크 매니저를 거쳐야 체결됩니다. 나스닥 종목만 다루며, 하루 목표는 시드의 0.5%입니다.

가상 시세(랜덤워크)와 규칙 기반 모의 에이전트로 돌아가는 시뮬레이션입니다. 실제 시장 데이터나 실제 매매가 아닙니다.

코드로 강제하는 규칙

  • AI는 의견만 낸다에이전트는 JSON만 반환하고, 주문은 리스크 검사를 통과한 코드만 냅니다.
  • 0.5%는 상한목표에 닿으면 신규 매수를 막고 청산만 허용합니다.
  • −1%면 멈춘다일일 손실 한도에 닿으면 전량 청산하고 그날 매매를 중단합니다.
  • 비중 한도종목당 10%, 주문당 5%, 총 노출 50%, 포지션별 손절 1.5%, 하루 20건.
  • 선보고 의무주니어 아이디어는 담당 시니어의 워치리스트와 맞아야 승인됩니다.
  • 실계좌는 사람 승인Python 버전의 --live 모드는 주문마다 터미널에서 yes를 입력해야 전송됩니다.

직접 실행하기

python main.py                 # 모의 에이전트 + 샘플 시세
python main.py --llm claude    # 내 PC의 Claude Code로 판단 (도구 0개로 격리)
python -m unittest discover tests

이 페이지는 Python 버전(trading_office/)의 MockLLM·리스크 로직을 브라우저로 옮긴 데모입니다. 투자 조언이 아닙니다.
